# GrapeLeafi-QQbot

**本机自建的 QQ 机器人框架 —— 基于 NapCatQQ 的真实 NTQQ 会话，不租服务器，不开放入站端口，内置整套防风控机制。**

NapCat（协议端）与本机 Node.js 客户端之间只走 `127.0.0.1` 上的反向 WebSocket，QQ 号、token、玩家数据都留在自己电脑上。

```
┌──────────────┐   反向 WebSocket（仅本机）    ┌──────────────────────────┐
│ NapCat 协议端 │ ───────────────────────────▶ │ Node.js 客户端            │
│ 本机 QQ + 注入 │  ws://127.0.0.1:8181/...    │ 网关 + 防风控 + 指令路由   │
└──────────────┘   不开放任何入站端口          └──────────────────────────┘
                                                          │
                                              本地控制台 127.0.0.1:9632
```

> ⚠️ **任何形式的 QQ 自动化都有封号风险。** 请用小号（新号先养号），不要用常用大号。协议逆向可能违反腾讯服务条款，风险自行评估。详见 [防风控清单](docs/anti-risk.md)。

---

## 快速上手

1. 装 **QQ 桌面版（NTQQ ≥ 9.9.22）** 和 **Node.js 18+**。
2. 双击 `start.bat` —— 缺依赖自动装、缺 NapCat 自动下载、缺 `config.json` 自动从模板生成。
3. 按提示用 QQ 扫码登录（只有第一次会弹二维码）。
4. 用**另一个 QQ** 私聊机器人或拉它进群，发 `/ping`、`/签到`、`/help`。

控制台在 <http://127.0.0.1:9632>，打开就能改配置、看日志、发测试消息。

### 唯一要手填的一项：`bot.adminIds`

只有 `/设置`、`/修复` 这类**主人指令**需要它，聊天、签到、图鉴、抽卡、运势全都不需要，**留空也能正常玩**。

要填就在控制台「设置」页填 QQ 号并保存（立刻生效，不用重启），或直接改 `client/config.json`。

> 必须填**你用来跟机器人聊天的那个号**，不能填登录机器人的号 —— 机器人会忽略自己发的消息（`self_id === user_id` 直接 return，这是防止关键字无限回环的必需判断）。所以想让 bot 认你当主人，手上得有**第二个 QQ**。

## 功能速览

| 分类 | 内容 |
|---|---|
| 内置指令 | 签到 / 等级 / 面板、抽卡 / 图鉴 / 保底 / 分解、钓鱼 / 运势 / 抽签、头衔、生日、文娱、互动、联网、群管理等 |
| 抽卡系统 | 光玉货币、作品池与角色池、SSR/SR+ 双保底、731 张卡的元数据（素材自备） |
| 签到与等级 | 余额与累计积分分离，**花积分不掉级**，等级按 `100 × N` 累计升级 |
| 聊天回复 | 关键字回复、分时段文案、随机多条、图库随机抽图、群内自建指令、HTTP 接口指令 |
| AI 对话 | OpenAI 兼容协议，可接 DeepSeek / Kimi / 通义 / OpenAI；带上下文、可设人设；自动剥离思考过程 |
| 本地控制台 | 网页改全部配置、指令开关、卡池概率、生日表、定时提醒、实时日志与一键重置风控 |
| 防风控 | 全局随机节奏、会话串行、突发/小时/每日限额、失败退避与软静默熔断 |
| 存档保护 | 原子写 + fsync + 5 代滚动备份，损坏即停，绝不静默清零 |

完整清单见 [功能一览](docs/features.md)（含每条指令的说明、积分规则、数据文件说明）。

## 目录结构

```
bot/            NapCat 协议端（不进版本库，install.bat 自动下载）
client/         Node.js 客户端
  src/            网关、防风控、指令分发、AI、控制台
  data/           用户内容与玩家存档（不进版本库）
  config.json     个人配置（不进版本库，从模板生成）
assets/         图片素材（不进版本库，仅保留说明）
scripts/        下载 / 启动 / 打包 / 泄漏扫描脚本
launcher/       C# 启动器（定位 QQ 并注入）
docs/           详细文档（见下）
start.bat       主启动
install.bat     首次配置：装依赖 + 下载 NapCat
share.bat       生成去个人化的分享包
```

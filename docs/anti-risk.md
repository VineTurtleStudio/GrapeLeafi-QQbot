# 防风控清单

> 本文是 [GrapeLeafi-QQbot](../README.md) 的详细说明，内容与主 README 同步维护。

## 防风控清单（务必阅读）

> 风控 = 腾讯对账号/群消息的限制，严重时封号。选型（真实 QQ 会话）只是基础，**使用习惯决定生死**。

**发送侧（客户端已自动实现，`client/config.json` 可调）**
- 并发发送：最多 `concurrency`(3) 条同时发送；**同一群/同一人严格排队串行**，不同群/不同人互不阻塞——某条大图上传慢，也不会卡住其它会话；
- 全局随机节奏：每条 bot 消息之间至少间隔 `minDelayMs~maxDelayMs`（默认 0.6~1.8 秒随机）；
- 同群/同人冷却：刚给某群/某人发过，`groupCooldownMs`/`userCooldownMs`（默认 3 秒）内同目标排队等待（不丢，只是稍后发）；
- 突发限流：`burstWindowSec`(60s) 内最多 `burstLimit`(20) 条，超出自动排队等待；
- 小时上限：`hourlyCap`(120) 条/小时，超出自动排队等待；
- 每日上限：`dailyCap`(500) 条/天；每群每日 `groupIdDailyCap`(200) 条/天，超出直接丢弃；
- 重复抑制：`sameTextGapMs` 默认 **0 = 关闭**（不再丢弃重复文本）。想开启就设成毫秒数（如 `60000`），只对**同一会话**的相同文本生效（不同群互不影响）；
- 发送超时：`sendTimeoutMs`(**当前 120s**，默认 120000，兼容大图上传) 内没等到协议端回执才算失败——网络/超时类失败会自动重试 1 次（间隔 2s），连续失败才累计；
- 自动退避：发送被腾讯拒绝时惩罚倍率翻倍，最高 `maxPenalty`(4x)，冷却随之拉长；成功一次即恢复；失败连击超过 5 分钟无新失败自动清零，不累计旧账；
- 软静默（风控熔断）：连续 `autoMuteFailStreak`(3) 次发送失败 → `autoMuteMinutes`(5 分钟) 内不再外发；可在控制台「状态与日志」一键重置；
- 队列保护：`maxQueueLength`(200) 满时新消息直接丢弃（不堆积）；等待超过 `maxQueueWaitMs` 的任务作废；
- 长文本截断：`maxTextLength`(500) 以上截断，避免一次性大段刷屏；
- **可视化**：控制台「风控·节流」页可直接覆盖上述绝大多数参数（含 `setRuntime`），保存后实时生效并写进 `content.json` 的 `settings.riskgate`，不必改配置重启。

**接收侧（客户端 Brain 已实现，同样可在 `client/config.json` 调）**
- 私聊白名单：模板里是 `replyPrivate:"all"`（开箱即用，陌生人私聊也会回）；收紧成 `"whitelist"` 后只有 `adminIds`/`privateWhitelist` 里的 QQ 能私聊触发。**注意**：`whitelist` + 两个名单都空 = 所有私聊被静默丢弃（日志里只有一行 `[gate] 私聊对方不在白名单`），这是「能收不能回」的头号原因；
- 深夜静默：`quietHours.enabled` 默认 **false（已关闭）**；想开启就设为 `true`，并可用 `start`/`end`（默认 23:30~06:30）与 `allowGroups` 白名单（主人不受限）；
- 群回复节流：`groupReplyGapMs`(3s) 只作用于**未被点名时的自动接话**（关键字）；指令（`/xxx`）与 `@bot`/喊昵称一定会回，不会被群里别人的闲聊“吃掉”机会；
- 用户频率上限：`userRateLimit`(300s/20) 内每个用户最多触发 20 次回复，防单人在群里连发指令刷屏（管理员不受限）；
- 忽略 at-all：消息含 `@全体成员` 一律忽略，防止被全员艾特恶意联动；
- 忽略自身消息：OneBot 上报的自身消息（`report_self_message`）不处理。

**账号侧（需要你自律）**
1. **用养好的小号**，不要用大号/常用号；
2. 登录方式用**手机扫码**（不要在没验证过设备的机器上频繁登录）；
3. **稳**是第一原则：固定设备、固定网络、尽量固定时间段在线；
4. 不要一开机就大批量加群/拉好友；新账号先正常聊天养几天再挂 bot；
5. 上线初期把 `minDelayMs/maxDelayMs/groupCooldownMs` 调大，观察三天无异常再逐步收紧；
6. 避免发营销/广告类内容（最容易风控），也避免秒回一切；
7. 手机上偶尔正常手动使用该账号，保持真人活跃特征。

**网络安全侧**
- 反向 WS 只连接 `127.0.0.1`，**本机不开放任何入站端口**，token 与客户端一致才授权；
- NapCat WebUI 已改为只监听 `127.0.0.1:6099`（见 `bot\napcat\config\webui.json`），不要把端口暴露到公网。

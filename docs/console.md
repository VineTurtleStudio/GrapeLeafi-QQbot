# 本地控制台

> 本文是 [GrapeLeafi-QQbot](../README.md) 的详细说明，内容与主 README 同步维护。

## 本地控制台

启动客户端后，浏览器打开 **http://127.0.0.1:9632**（或 **http://localhost:9632**，只监听本机，不对外网开放）：

- **设置**（新）：**直接在网页上改 `config.json`，不用碰代码**。最重要的一项是**主人 QQ 号**——填谁谁就是主人，改完点保存**立刻生效，不用重启**。同类还有昵称、指令前缀、私聊/群回复范围、免打扰时段、频率限制、AI 接口与 key、小游戏冷却、发送器风控数值等。密钥类字段（网关 token、控制台 token、AI key）**不回显**，只显示「已设置」，留空即保持原值；要清空得点「清空」按钮。带「需重启生效」标记的项（网关监听地址/端口、控制台自身配置、`antiRisk`）改完要重启客户端。**页面顶部有吸顶的分区跳转栏**，11 个分区一键直达，滚动时自动高亮当前分区；**这一页在 `content.json` 读不出来时依然能打开**——配置坏了的时候恰恰最需要它来修；
- **手机 / 局域网访问**：设置页里有一块专门显示「现在手机上能不能打开控制台」。两个条件缺一不可：把「控制台自身」的 `host` 从 `127.0.0.1` 改成 `0.0.0.0`，**并且**在同一处设一个访问 token（不设 token 而开放非本机地址，客户端会直接拒绝启动，这是有意的）。配好后这一块会列出本机所有局域网 IPv4 地址和**可直接复制的完整地址**（已带 token），在手机浏览器里打开即可，**之后建议「添加到主屏幕」当 App 用**。复制按钮在 http 局域网页面上有降级方案（`navigator.clipboard` 不可用时改用 `execCommand`，再不成就提示长按选中），不会出现「点了没反应以为复制成功」；
- **手机浏览器可用**：页面已做窄屏适配——补了 `viewport`（不补的话手机会把整页缩小到点不准）、表单在窄屏改成竖排整行铺满、宽表格（内置指令 8 列、定时任务等）保持最小宽度并在卡片内横向滑动，按钮加大到好点的尺寸；
- **预设指令**：可视化增删改「指令名/别名/简介 → 回复(默认)/早/午/晚/夜/随机多条/图片/冷却/仅管理员/限定群/私聊可用」，回复支持模板占位符（文本框上方有**占位符一键插入按钮**），顶部有**一键模板**（掷骰/灌注@/接口指令）与**搜索过滤**，卡片可**点击标题折叠**；并可**配置 HTTP 接口**把指令变成「调用外部链接处理 → 回复/合并转发」，无需改代码；
- **关键字回复**：管理自动接话的关键词（**一行一个、一条回复可配多个关键字**），同样支持分时段文案、随机多条、图片、**图库目录（递归子文件夹随机抽图）**、模板占位符，以及「包含/整句/正则/仅@时/排除词」触发条件；群内 @bot 自建的「本群指令」也保存在这里（带「本群」标记、限定群=该群）；
- **说明书**：控制台内置「说明书」页，对机器人的三种触发方式、内置指令速查、**全部占位符一览表**（含例子）、关键字玩法、群内自建指令、HTTP 接口指令、风控/静默常识及控制台操作技巧做了完整图文说明；
- **自动保存**：任意输入改动后 **2.5 秒无输入即自动保存并热重载**（顶栏显示状态）。手动保存统一用右上角的**「💾 立即保存」**，它会把内容与卡库一起写入；早期各页面底部那个「立即保存并重载」已删掉——它只存内容不存卡库，在抽卡管理页点它卡库改动其实没落盘，反而误导；
- **多窗口/多设备互不覆盖**：保存按「条目」合并而不是整文件覆盖——同一预设指令、关键字或二次元图片源按稳定 ID/名称合并，不同窗口各加各的都会保留，旧快照不会冲掉其他窗口的新条目；删除仍生效（带删除标记，删除的条目不会复活）。**同名即同一条目**（改名=新条目）；切换标签页/窗口时自动同步最新数据；
- **内置指令**：逐条开关内置指令（`/ping` `/help` 等），可单独调冷却、设仅管理员、限制群、关掉私聊使用（键名为指令规范名，如 `me`/`mute`/`运势`/`抽卡`）；**按 11 个分类分组显示**（基础、小游戏、日常、查询、生日、群管理、互动、权限、文娱、联网、管理），顶部有**吸顶分类跳转栏**，滚动时自动高亮当前分类、点击时目标闪一下确认落点；新增内置指令后记得同步 `src/brain-registry.js` 的 `CMD_CATEGORY`/`NAME_MAP` 和控制台的 `BDEFS`，否则控制台里看不到它；长页面（抽卡管理、生日、二次元图片、回复设置）同样各有一条吸顶跳转栏，吸顶位置跟着 header/nav 的实际高度走，窄屏也不会错位；
- **回复设置**：切换「自由回复」与「仅 @ 回复」、「回复时引用原消息」开关；同页维护「**群指令开关**」（`settings.groupEnabled`，形如 `cat:生日: 999999` 按行编辑）、「默认关闭清单」`defaultOff` 与「**群事件回应**」（入群欢迎/退群提示/戳一戳的文案与启用群）；戳一戳那栏多一个「**同时响应好友/私聊戳一戳**」开关（`allowPrivate`，默认关）——OneBot 的 poke 事件在好友场景下不带 `group_id`，代码靠这个开关才放行私聊回复；
- **群门控**：设置全局应答群白名单 `replyGroups`、黑名单 `blockGroups`、深夜静默白名单 `quietAllowGroups`；
- **风控·节流**：可视化覆盖群/私聊/AI 节流间隔（`gates`）与全部风控参数（`riskgate`：冷却/突发/小时/每日上限等），保存后实时生效并持久化到 `content.json`；
- **AI 设置**：编辑 systemPrompt 人设与兜底话术；
- **二次元图片**：独立维护 `/随机二次元` 的 API 列表，可新增、编辑、启用/停用、标记非18+、测试和删除；支持 JSON、文本 URL、重定向及直接图片响应。客户端会固定使用已校验的公网 IP 发起请求，拦截内网/保留地址与私网重定向，限制下载大小并校验图片格式、尺寸；大图会压缩后以 Base64 发送，配置保存到 `content.json` 的 `anime` 节点；
- **抽签图片**：设置签图目录并扫描预览；
- **生日**：总开关/推送时间/推送文案/已开启群维护；内置 Key 社角色生日条目列表（**支持粘贴批量导入或读 txt 文件**，同名同日期自动跳过、`02-30` 这类不存在的日期当场挑出，名字里带空格不会切碎），列表带**搜索（同时搜名字和作品）/来源筛选/按日期·名字·作品排序/每页 60 条分页**，可只删筛选出的条目、或把筛选结果导出成文本再改改导入（默认按群关闭）
- **定时提醒**：增删改定时群推送；
- **状态与日志**：实时发送统计（每 2 秒自动刷新）、协议端连接状态、队列/发送中/软静默、最近运行日志，可**直接发测试消息**，也可**一键「重置风控 / 解除软静默」**。

改动点「保存全部并重载」即热生效，无需重启客户端（`content.json` 里的内容类改动都是热生效；「设置」页改的 `bot` 段同样热生效，只有标注「需重启」的少数项要重启）。
用户内容存放在 `client/data/content.json`（可手动编辑，格式同控制台）。

### 控制台安全边界（分享前必读）

控制台是**只给主人自己用的后台**，不是给普通用户的产品界面：它能改全部 `config.json`、看群列表、调主人 QQ 号，还能通过素材接口读本机图片文件。所以：

- **不要把控制台地址分享给普通用户**，也不要把访问 token 发出去；
- **不要做端口转发把它暴露到公网**。异地访问请走 VPN / Tailscale；
- 只在**自己信任的 Wi-Fi** 下用局域网地址打开，用完把 `host` 改回 `127.0.0.1` 最省心；
- 页面响应统一带 `Referrer-Policy: no-referrer` / `X-Frame-Options: DENY` / `X-Content-Type-Options: nosniff`，`?token=` 在页面加载后会**立刻从地址栏抹掉**（只留在内存里），避免留在浏览器历史或被当成 Referer 带出去；同一来源连续输错 token 达 8 次会**锁 2 分钟**，防止局域网内被暴力猜。

**想让别人用这个机器人？** 正确姿势不是把控制台发出去，而是把机器人**拉进对方的群**、把对方加进 `replyGroups`（或设 `replyPrivate: "all"` 开放私聊），需要的话在控制台「群门控」里单独给这个群配规则。对方直接用 QQ 和机器人聊天即可，全程不接触控制台。
